## Install from the Kleeja Store

Kleeja ships with a built-in store, so most plugins need no downloading at all. Open the **Plugins** page of the Kleeja Admin Panel and switch to the **Kleeja Store** tab.

The store lists the official plugins with their descriptions and latest versions. Click **Install** next to the one you want, and Kleeja fetches the archive and unpacks it for you. The plugin then appears in the available plugins section, ready to enable.

::note
Only the founder account can install from the store, and Kleeja refuses any package that does not support your version of Kleeja.
::

::tip
The store lists only the plugins you have not installed yet. To upgrade the ones you already run, open **Check for updates** on the same page, then update them one by one or with **Update All**.
::

The store offers the same plugins this website lists on the [Plugins & Styles](/plugins) page.

## Find a plugin to install

Install a plugin from a file when it is not in the store, or when your server cannot reach the store.

Download a plugin that you like from the internet.

::warning
Make sure you trust the developer — plugins can break your website and spy on you.
::

::note
Plugin file format: a plugin comes as a `zip` archive file.
::

![A plugin archive file](/images/docs/plugin-archive.png)

## Upload it to Kleeja

From the **Plugins** page of the Kleeja Admin Panel, click on the **Upload from your computer** button and choose the plugin archive file.

![Uploading a plugin from the Admin Panel](/images/docs/plugin-upload.png)

## Enable the plugin

After uploading the plugin file, the plugin appears in the available plugins section. Click on the **enable** button in front of its name.

![Enabling a plugin](/images/docs/plugin-enable.png)

Congratulations, you installed and enabled a plugin.

::note
During the plugin installation, a page with after-installation notes appears. Make sure you read it and follow any instructions shown there.
::

::note
If the plugin has extra options, they appear on the settings page or as a separate side menu item.
::

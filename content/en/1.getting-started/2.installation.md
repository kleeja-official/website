## Upload Kleeja files to your website

After downloading Kleeja you will have a zip archive. Extract it and you will get a folder titled `kleeja`.

![The extracted kleeja folder](/images/docs/kleeja-folder.png)

- The `kleeja` folder is what you have to upload to your website using any FTP application.
- You can rename the `kleeja` folder to anything you like, such as `up` — short for upload.
- If you don't want Kleeja to live in a sub-folder, upload only the **contents** of the `kleeja` folder to your website. You will then get Kleeja on `example.com` instead of `example.com/kleeja`.

## Request the Kleeja installation wizard

::note
This step comes after uploading the Kleeja contents to your website.
::

Using any browser, request this link:

```bash [Browser]
example.com/kleeja/install
```

Where:

- `example.com` is your domain.
- `kleeja` is the folder where you uploaded the Kleeja contents.

## Installation wizard steps

::steps{level="3"}

### Choose your language

The first step gives you a list of languages — choose yours.

![Language selection step](/images/docs/install-language.png)

### Read the information about Kleeja

Then you will see information about Kleeja. Click **next**.

![Information about Kleeja](/images/docs/install-info.png)

### Start the installation

A step with an install icon appears. Click **install**.

![Install step](/images/docs/install-start.png)

### Accept the license

The license page is shown. Click **next** to accept it.

![License page](/images/docs/install-license.png)

### Check the server functions

Kleeja checks the server functions. If nothing is wrong, a **next** button appears — click it. Otherwise, make sure you fix the errors shown before moving on.

![Server functions check](/images/docs/install-server-check.png)

### Fill in the database information

The next step requires your database information. Fill it in and click **next**.

::tip
You can create the database from cPanel before starting this step.
::

![Database information step](/images/docs/install-database.png)

### Create the configuration file

Kleeja tries to create the configuration file in this step. If Kleeja cannot create it, the file is given to you so you can upload it manually before continuing.

![Configuration file step](/images/docs/install-config-file.png)

::note{to="/guides/config-file"}
Learn what every option in `config.php` does.
::

### Check the connection

Kleeja checks the connection and the MySQL version. Click **next** if everything is OK.

![Connection and MySQL version check](/images/docs/install-db-check.png)

### Fill in your site information

Kleeja asks you to fill in some information about your site, such as the website name and your admin account.

![Site information step](/images/docs/install-site-info.png)

### Create the database tables

Kleeja then creates the database tables. Click **next**.

![Creating database tables](/images/docs/install-tables.png)

### Delete the install folder

Congratulations, Kleeja is installed. All you have to do now is delete the `install` folder.

![Installation finished](/images/docs/install-done.png)

::

::warning
Leaving the `install` folder on your server after the installation is a security risk. Delete it before using your upload center.
::

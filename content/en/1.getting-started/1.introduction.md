Welcome to the **Kleeja** documentation, the online manual for Kleeja and a living repository for Kleeja information and documentation.

Kleeja is a file upload script written in PHP. You install it on your own hosting, and it turns any domain — or any folder on it — into a complete upload center with its own users, styles, plugins and Admin Panel.

## Key features & highlights

- Multi-lingual.
- Plugins system (download, install and update from the Admin Panel).
- Auto update system (from the Admin Panel).
- User-friendly interface with multiple file fields.
- Advanced file types management system.
- Limited upload space.
- Google Analytics support.
- User integration (vBulletin, phpBB, etc.) through plugins.
- Watermark on images.
- Generate image thumbnails.
- Report-abuse system.
- Advanced contact system.
- Cache system.
- User registration control (on/off).
- Maintenance mode with a custom message.
- UTF-8 encoding.
- Adjustable waiting period for downloading.
- Mass banning system.
- Multiple admins (Admins or Founders).
- Total repair system (caching, counters re-calibrating).
- Filenames manipulation (by "time", "MD5 encryption" or a custom prefix).
- Advanced admin dashboard.
- Custom terms of service.
- File deletion URL.
- Spam & flood protection.

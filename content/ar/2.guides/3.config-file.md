من أهم الملفات في تثبيت كليجا لديك هو ملف `config.php`. يوجد هذا الملف في المجلد الرئيسي لكليجا، ويحتوي على الإعدادات الأساسية لموقعك، مثل بيانات الاتصال بقاعدة البيانات.

## أين يوجد ملف config.php

عند تحميل كليجا لأول مرة لا يكون ملف `config.php` موجودًا ضمن الملفات. [عملية تثبيت كليجا](/ar/getting-started/installation) هي التي تنشئ لك ملف `config.php` بناءً على المعلومات التي تدخلها.

## إنشاء ملف config.php يدويًا

يمكنك إنشاء ملف `config.php` يدويًا بنسخ الكود البسيط التالي:

```php [config.php]
<?php
$dbserver   = 'localhost'; // خادم قاعدة البيانات
$dbuser     = 'user';      // مستخدم قاعدة البيانات
$dbpass     = 'pass';      // كلمة مرور قاعدة البيانات
$dbname     = 'kleeja';    // اسم قاعدة البيانات
$dbprefix   = 'klj_';      // البادئة الخاصة بأسماء الجداول
```

::tip
ننصحك بألا تقوم بذلك يدويًا — اتبع عملية التثبيت ليُنشأ هذا الملف تلقائيًا.
::

ابتداءً من كليجا 3.1.0 يمكنك استخدام `$dbtype = 'sqlite';` لاستعمال محرك قاعدة بيانات SQLite بدلًا من MySQL.

## الخيارات المتقدمة

يوفّر كليجا العديد من الإعدادات المخفية لجعله يعمل على النحو الأمثل بالنسبة لك، ولحل بعض المشكلات التي يواجهها بعض المستخدمين.

::warning
لا تستخدم هذه الخيارات إلا عند الحاجة.
::

لاستخدام أحدها، انسخ الكود المطلوب والصقه في نهاية ملف `config.php`.

| الكود | الوصف |
| --- | --- |
| `defined('MAKE_DOPHP_301_HEADER', true);` | استخدام إعادة التوجيه 301 لتحميل الملفات مباشرة (يساعد على تحسين الأداء). |
| `define('DEV_STAGE', true);` | تفعيل وضع التطوير (للمطوّرين). |
| `define('STOP_PLUGINS', true);` | تعطيل نظام الإضافات، لتتمكن من حذف الإضافات المعطوبة أو إيقافها. |
| `define('STOP_CAPTCHA', true);` | تعطيل نظام الكابتشا إذا كنت تواجه مشكلات فيه. |
| `define('TIME_FORMAT', 'd-m-Y h:i a');` | تغيير صيغة عرض التاريخ في كليجا إلى ما تريده. |
| `define('DISABLE_INTR', true);` | تعطيل تكامل نظام المستخدمين مع تطبيقات الويب الأخرى. |
| `define('FORCE_COOKIES', true);` | إذا كنت تواجه مشكلة في تسجيل الدخول بسبب إعدادات الكوكيز. |
| `$config_cookie_name = ''; $config_cookie_domain = ''; $config_cookie_secure = ''; $config_cookie_path = '';` | أو استخدم أيًا من إعدادات الكوكيز هذه بشكل منفرد. |
| `define('STOP_CSRF', true);` | يضيف طبقة حماية إضافية إلى لوحة تحكم كليجا. |
| `define('ACP_IMAGES_PER_PAGE', 20);` | عدد الصور في الصفحة الواحدة داخل لوحة تحكم كليجا. |
| `define('ACP_FILES_PER_PAGE', 20);` | عدد الملفات في الصفحة الواحدة داخل لوحة تحكم كليجا. |
| `define('HAS_SUEXEC', true);` | حل للاستضافات التي تعمل تحت suexec. |

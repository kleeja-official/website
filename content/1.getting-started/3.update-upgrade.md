::warning
Always take a backup of your files and your database before updating.
::

## Auto-update (Kleeja 3.1.0 and later)

From version 3.1 you can update Kleeja from the Admin Panel, on the **check for updates** page. Follow the steps from there.

## Upload Kleeja files to your website (manually)

Download the latest version of Kleeja from the releases page:

::card
---
icon: i-lucide-download
target: _blank
title: Kleeja releases
to: https://github.com/kleeja-official/kleeja/releases
---
github.com/kleeja-official/kleeja/releases
::

After downloading Kleeja you will have a zip archive. Extract it and you will get a folder titled `kleeja`.

![The extracted kleeja folder](/images/docs/kleeja-folder.png)

Upload all files from the `kleeja` folder to your website using any FTP application, replacing the old files — **except the `uploads` folder**.

## Request the Kleeja upgrade wizard

::note
This step comes after uploading the Kleeja contents to your website.
::

Using any browser, request this link:

```bash [Browser]
example.com/kleeja/install
```

Where:

- `example.com` is your domain.
- `kleeja` is the folder where you uploaded the Kleeja contents.

Go through all the steps until you get the **update** button, then click it.

If there is an update to the database, Kleeja displays it to you — choose it and continue.

Congratulations, Kleeja is updated now.
